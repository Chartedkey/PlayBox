# PlayBox

Оболочка для эмуляторов PS1 (DuckStation), PS2 (PCSX2) и PS3 (RPCS3) на Godot 4.
Приставки выезжают из коробок, игры стоят на полке, а диск выезжает из коробки перед запуском.

BIOS, игры и эмуляторы в проект не входят.

## Картинки

Изображения приставок, логотипы и обложки не хранятся в репозитории.
Положите папку `assets` рядом с `PlayBox.exe`. Без неё программа покажет нейтральные заглушки.

```
assets/
  ps1/  console.png  box_front.png  box_side.png  box_top.png
  ps2/  ...
  ps3/  ...
```

Для запуска из редактора используйте папку `assets_local` в корне проекта.

## Разработка

- Тесты: `godot --headless --path . --script res://tests/run_tests.gd`
- Каждый push собирает версию для Windows, а тег `v*` публикует релиз.
